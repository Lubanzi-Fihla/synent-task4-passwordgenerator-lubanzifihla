# Password Generator

## Description

This project is a simple Python-based Password Generator that creates secure random passwords based on the length specified by the user.

## Objective

To generate strong passwords containing a mixture of:

- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

## Features

- User chooses password length
- Random password generation
- Supports uppercase and lowercase letters
- Includes numbers and special characters
- Simple command-line interface (CLI)

## Technologies Used

- Python 3
- random module
- string module

## How to Run

1. Open a terminal.
2. Navigate to the project folder.
3. Run:

```bash
py main.py
```

4. Enter the desired password length.
5. The generated password will be displayed on the screen.

## Sample Output

```text
Password Generator
Enter password length: 12
Generated Password: A#7kL@9mP!2q
```
